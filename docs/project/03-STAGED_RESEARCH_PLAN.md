# 03｜研究实施路线：先数据证据，后科研任务

本 Plan 属于**候选可调整阶段路线**。只有 R0 是当前必须执行；R1–R8 的具体任务和先后依获得数据与用户决定重排。不要把此文件视为用户已批准全部技术栈或已实际完成任一阶段。

## R0｜数据准入、实验任务判定与硬件盘点（NOW）

核心工作：按 D01 FlexFair、D02 CCMD、D03 TCIA 顺序核实真实下载/授权、成像格式、Mask、患者/中心/时间信息、字段定义、许可及原始来源重叠；核对 OS/GPU/VRAM/磁盘容量。

验收：产出患者级/文件级数据清单、字段字典、至少一对真实可加载的 Image+Mask（如数据允许）、每个候选的 GO/CONDITIONAL/NO-GO；明确首个主任务究竟是 2D/3D 分割还是分割后特征稳定性。数据无法合法取得时允许重新调研，不把学习停摆视为失败。

**门槛**：没有真实图像+Mask 就不进入监督分割训练；没有对应治疗/预后标签就不做临床结局预测。

## R1｜从零构建可诊断 Python 环境

按硬件和数据选 CPU/本地 GPU/适当运行环境；学习 Python、venv/conda/uv、Jupyter/VS Code、pip、PyTorch、NumPy、nibabel、SimpleITK、PyRadiomics（按需要）。先建立小型环境验证脚本、`python --version`、`torch.cuda.is_available()`、依赖锁，不安装无必要全家桶。

验收：用户亲自执行并解读版本/设备/依赖，记录命令、stderr/stdout 和关键环境；一段小程序可以载入单个合规影像示例。未运行不得写 SUCCESS。

## R2｜医学影像格式与空间质控

患者级索引、序列/时点、体素与物理坐标、DICOM/RTSTRUCT、NRRD/NIfTI、Spacing/Direction/Origin、切片顺序、ROI 重采样与对齐、匿名信息检查、患者级划分。构建 image-mask overlay 并人工检查至少几个代表性病例。

验收：索引 CSV/JSON；Shape/spacing 统计；可复核 overlay；异常病例日志；分割目标定义，排除空掩膜/错位/错误器官。

## R3｜基线分割（仅在 Mask 已确认时）

先简单可信 baseline：例如 U-Net 或可运行的 nnU-Net；根据发布数据结构选择 2D 或 3D，不预设有完整 3D MRI。固定患者级划分，中心分布与同人切片不跨集合。指标 Dice、IoU、HD95/NSD（适用时）、逐中心及病灶大小分组误差分析。

验收：一次真实训练-验证-独立保留评价闭环；权重、配置、数据版本、指标与定性失败示例；不要求立即高于论文。

## R4｜稳健 Radiomics（需要有物理空间的可靠 ROI）

PyRadiomics 手工特征（强度、形状、GLCM、GLRLM、GLSZM）、固定预处理、特征稳定性。分割扰动与跨预处理设置鲁棒性检验；在适当条件下 ICC/相关性等。仅有 2D PNG 而无 spacing/体积时，限制为有效的 2D 实验，不虚构体积或三维形态指标。

验收：可重复导出的特征表；特征定义、图像单位和尺度；扰动前后误差分布、稳定性选择结果，至少一个可检验的假设和对照。

## R5｜Habitat 与深度表征（选择性分叉）

若存在空间对齐的多序列或合格的纹理特征：逐体素表征→聚类/亚区域→重采样稳定性→全肿瘤 vs Habitat 消融。也可走 CNN/ViT 冻结特征提取路线。不要因为用户希望较难而强制把 ViT、Transformer、Habitat、Mamba 堆成一体。

验收：定义 Habitat 的输入、聚类数选择、区域稳定性与可解释性；排除切片/同人信息泄漏；确实发现相对于 baseline 的可解释收益才升级。

## R6｜分布偏移与跨中心（需要可核查中心标识）

内部中心划分、Leave-one-center-out、数据来源/时间重复查重、设备/spacing 差异、校准或迁移学习。若仅有四中心切片而无患者 ID，不能宣称患者级跨中心泛化，先修复数据治理。

验收：明确训练中心、测试中心、患者互斥；总体与分中心报告；失败案例与方差/置信区间。

## R7｜患者级治疗应答/生存预测（条件分支）

需通过临床标签审查：确切干预 NACT/NACRT/CRT，影像采集时间，CR/PR/pCR 定义，参照标准与随访日期、治疗后信息边界；有足量样本才进行可信监督建模。此时才选择 SVM/RF/CNN/Transformer/融合、AUC、PR-AUC、Calibration、DCA 或生存模型 C-index。

验收：按病人/中心隔离训练、调参、最终测试；SMOTE/标准化/筛选只在训练折；分类输出正类方向固定；报告置信区间、失败、无法达到原论文指标的原因。无标签时本阶段允许长期搁置。

## R8｜研究贡献及最终收口

基线—明确假设—受控改动—消融—独立检验—误差分析—可复现工程资料/研究报告。创新主张由实验驱动；不保证发表、更不保证所谓“突破性”。对数据许可和患者隐私保持严格边界。
